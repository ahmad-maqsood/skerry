# Security Policy

## Supported Versions

Security fixes are released for the latest stable version of Skerry.

| Version | Supported |
| --- | --- |
| Latest stable release | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Skerry, please report it privately rather than opening a public issue.

- **GitHub Security Advisory**: Submit a private advisory through the [Security tab](https://github.com/ahmad-maqsood/skerry/security/advisories/new) on GitHub.

### What to Include

Please provide:
- A description of the issue and potential impact
- Detailed reproduction steps or a minimal proof of concept
- Your environment details (Windows version, Skerry version)

### Response Timeline

- Initial acknowledgment within 48 hours
- Assessment and patch development within 7 business days
- Coordinated public disclosure after a patched release is published
