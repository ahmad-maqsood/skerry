## Now Playing 

Redesigned from scratch following Apple Dynamic Island / Now Playing, Spotify Mini Player, and Windows 11 media flyouts. (Agent inference)

- **No longer a card**: the music page renders directly on the island, without card backgrounds or borders; the island itself is the player. Hierarchy relies entirely on font size, weight, and whitespace.
- **Structure (top to bottom)**: Track (artwork + title + artist) -> Lyrics (when available) -> Progress bar -> Playback controls. Page height remains constant (island 320px).
- **When lyrics are unavailable**: artwork is 120px, title is 22px / 700 with up to two lines (truncated if long), artist is 14px, followed by a player chip in the accent color and the gray album name; when songs fail to find lyrics on LRCLIB, this line turns into an accent link opening Settings -> Music.
- **When lyrics are available**: artwork shrinks to 52px, title and artist occupy one line each (15 / 13px), ceding room to lyrics; artwork size and corner radius transition over 360ms. Lyrics show three centered lines , sharing center axis with progress bar and controls, with 60px margins on both sides for timing controls: active line is 18px / 600 at maximum brightness, previous and next lines are 13px gray with edge fade-out; on line change, new line slides up 8px from next line position with fade-in. Word-by-word lyrics light up word by word; translations replace next line when present. Track calibration (- 0s +) appears in lyrics top-right corner on hover or keyboard entry only.
- **Artwork**: rounded corners 16px (small artwork 12px) with a thin lit glass edge; blurred artwork layer underneath casts the track's colors (0.75 opacity playing, 0.3 paused). Behind the whole open island, header included, the blurred drifting cover and two soft radial washes of the accent color (dimmed when paused) fill the surface and are clipped only by the island's own outline, with no rectangular edge (`features/media/MusicBackdrop.tsx`). Artwork scales to 94% on pause, returning to 100% on playback (matching Apple Music). Gradient square with musical note displays when artwork is unavailable.
- **Accent Color**: calculates average color from artwork (weighting saturated pixels higher), adjusted for readability (`features/media/artworkTint.ts`), used for the ambient wash, player chip, progress wave, play button glow, jumping bars and lyrics links; falls back to soft white without artwork.
- **Top Right**: four jumping bars (pure CSS, jumping on play, falling on pause, static under reduced motion), beside microphone icon button "Lyrics Settings", opening Settings -> Music. Avoids gear icon because top bar already has settings gear.
- **Progress Bar**: full width; the played part is an accent-colored wave that travels while playing and lies flat when paused, dragged, or estimated (static under reduced motion), the rest is a flat 4px line; elapsed time on left, remaining time on right ("-3:26"), tabular numbers. When players omit durations (e.g. NetEase Cloud Music), adopts song duration from lyrics sources (LRCLIB, Kugou, NetEase search results); elapsed time tracked by island from initial sighting. Hidden only when neither source provides duration.
  - **Drag seeking**: progress bar supports clicking and dragging. A seekable bar shows a 4px x 14px upright handle that grows taller on hover, cursor is a pointer; dragging updates time and fill directly with cursor, issuing single seek on release (`media_seek` -> `TryChangePlaybackPositionAsync`), displaying new position immediately without waiting for player roundtrip. Keyboard: arrow keys seek 5s, Home / End seek start / end. Click target expands 6px vertically without affecting layout.
  - When player disallows seeking or duration is borrowed from lyrics sources (NetEase without plugin), progress bar remains read-only: no pointer cursor, no handle.
- **Playback Position Calculation** (
  - Media session timeline is a snapshot: `Position` corresponds to `LastUpdatedTime`, emitted at player discretion (Spotify and browsers emit on seek / pause / resume; others emit only on track change). Position = snapshot position + time elapsed since `LastUpdatedTime` * playback rate (`media_control/timeline.rs`).
  - Without new snapshots, pausing freezes position at calculated moment, resuming continues without accumulating pause duration; missing, zero, future, or overly stale timestamps treat time as "now"; players updating position without updating timestamps treat time as now. Seeks from island follow seek position even if player omits new snapshot.
  - Background thread subscribes to `TimelinePropertiesChanged`, `PlaybackInfoChanged`, `MediaPropertiesChanged` per session, emitting `media-session-changed` on changes; island re-reads immediately, syncing lyrics when seeking in player; 1.5s polling acts as fallback. Thread terminates 10s after music disables and reads stop.
  - Frontend re-anchors only when new reading differs from calculated position by over 300ms (seek, pause, correction) or track/playback state changes (`features/media/positionAnchor.ts`), preserving anchor otherwise to prevent re-renders and restarting word-by-word lyrics. Discrepancies over 1.5s snap without smoothing.
  - Known limitations: **NetEase Cloud Music** native SMTC omits timeline (position and duration both 0); island tracks elapsed time locally from track start, without following seeks in NetEase; installing InfLink-rs plugin provides full timeline. **Kugou**, AIMP, foobar2000 (without plugins) likewise lack timelines; legacy **QQ Music** (pre-21.10.2962) also lacks timelines. Position is not fabricated in these cases.
- **Playback Controls**: play / pause is a solid 48px inverse-color disc with an accent glow; previous and next are 40px translucent discs; spacing 20px; play grows slightly on hover, buttons compress on press. Buttons dim when actions are unsupported.
- **Idle State** : no longer an empty player without artwork, progress bar, or dimmed controls. Center grouping: static vinyl record on left (92px, grooves, dark label, subtle reflection, pure CSS, non-spinning), right side shows "Not playing", note "Play a track in any media player to display here", and quiet capsule button "▶ Resume playback" (sends media play key to resume last player; tooltip explains behavior). Neutral grays only, reserving color for album covers. Implemented in `MusicIdle.tsx`; inspection page `tests/regression/music-lyrics.html?view=idle`.
- Removed waveform (`MediaWaveform`): conflicted with lyrics space and created clutter. Collapsed bar music indicator (`MusicWaveButton`) retained, color changed from mint green to standard foreground gray-white (`--text-2`, hover `--text-1`), glowing green removed during playback (.
