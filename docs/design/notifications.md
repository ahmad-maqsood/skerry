# Notification Reading and Selection

Global direction see [DESIGN.md](../../DESIGN.md). Adds reading and reminder workflows within the existing island, utilizing system typography, semantic colors, compact controls, and island spring transitions. (, 2026-11-18)

- Settings -> Messages -> On-island notifications "Adaptive expansion for long messages" is disabled by default. When enabled, short messages remain single-line, longer messages widen first, wrapping to multi-line reading upon reaching maximum width; dimensions constrained by user ceilings and scaled stage boundaries. Max width 320-720, default 520px; max height 80-360, default 180px; dwell duration 3-60, default 12s. Body scrolls when exceeding height, without compressing font sizes. (, expanding width if truncated, wrapping once maximum width is exceeded. (User manual testing discovered long messages failed to expand island under estimation alone, 2026-11-18)
- Adaptive mail notifications always use reading layout, wrapping subject and on-demand body completely. Source icon serves as drag handle; sender and body selectable via cursor and copyable via Ctrl+C; pressing text neither drags window nor opens mail, open action handled by dedicated button. Omits "Copy full text" button (. Displays loading text during body fetch, retrying inline on failure. Reading notification body does not mark mail as read or open panels. Notification remains visible while cursor rests on island, dismissing after cursor leaves; hover expansion is suppressed during this interval. (
- Subject, sender, and body in mail panel are selectable and copyable via text selection without extra copy buttons. Selecting text or link text does not trigger open or drag actions; retains native right-click copy menu when selection exists. (issue #83; Agent implementation decision)
- Re-renders upon mouse release preserve original DOM nodes and selections in mail HTML body; object updates for the same mail do not re-focus or reset scroll position. Selection protection under hover focus covers mail subject, sender, body, and message previews, re-evaluating selection before returning delayed focus. 
- Notification shape entrance reuses existing expansion springs, exit reuses collapse transitions; reading body fades in briefly. Reduced motion disables body entrance while retaining existing island shape transition rules. (Agent implementation decision)

English: Adaptive notices are opt-in. They widen before wrapping, then scroll within user limits and the scaled native stage. Mail notices fetch the visible message body on demand, offer selectable text (Ctrl+C) and a separate open action, stay while the cursor is on them, and never mark the message read. Whether a message fits one line is measured on the laid-out bar, not only estimated. Game notices have their own opt-in and duration, display without taking focus, and keep native click-through enabled.
- Charger pop-up: on a laptop, the island pops out like a notification ("Charger plugged in" / "Charger unplugged" with the battery level) when the charger is connected or disconnected. The reading at start is not announced. Settings -> Messages -> "Show charger changes", on by default. Clicking it opens the System page.
