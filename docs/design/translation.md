# Translation Interface

See [DESIGN.md](../../DESIGN.md) for global directions.

## Translation Interface

- Quick translation references the translation UI shown at the reference mockup. (User confirmed: this request)
- Uses charcoal surfaces, compact headers, and language direction bar, organizing source text and translation with subtle divider lines; reuses system fonts and lucide icons. (Agent inference, based on reference interface)
- Color scheme uses only neutral gray-white : translation uses bright white (`#f0f0f3` / `--color-text`), primary translation button is light gray-white background with dark text, pure white on hover; focus outlines and input focus borders use translucent white, removing all green. Independent window matches in-island translation page.
- Default narrow window is stacked vertically, switching to side-by-side at 760px width; long texts scroll and wrap independently, settings area is scrollable. (Agent inference)
- Empty state provides clipboard entry, loading displays processing state, and shows "Copied" in-place after copying; preserves global shortcuts and Windows Credential Manager secret settings. (Agent inference)
- Translation services offer DeepSeek (default), Volcengine Ark, Qwen, Kimi, SiliconFlow, OpenAI, or custom OpenAI-compatible endpoints. Preset service endpoint URLs are fixed by native side; custom URLs must be https (http://localhost allowed locally); each service can customize model name (DeepSeek defaults to deepseek-flash when blank, others filled per provider docs), and API keys are stored separately per service. Toolbar displays current service name. (Upstream issue #15, user confirmed)
- Opening translation window with empty source automatically fills latest text clipboard (on by default, configurable); "Auto-translate after pause" can be enabled (off by default, sends only when window is open and typing pauses for approx 0.5s; does not send without API key). "Translate selected text" shortcut (default Ctrl+Alt+T) temporarily copies selection and restores clipboard, not recorded in clipboard history, translating clipboard text if nothing selected; translation displays on collapsed island for approx 8 seconds as a single line, prioritized behind message previews, clicking opens translation window for full text. No secondary source box in-island, no background clipboard/selection listening, and translations are not written back to clipboard. (User confirmed)
- Settings -> Translation selects "Open location": independent window (default) or in-island page. When in-island page is selected, top bar translation button, translation shortcut, and clicking translation on island all open expanded island translation page (direction bar, source, translation, single action row for paste / copy / translate), sharing service, keys, clipboard filling, and auto-translate settings with window; preserving source text across collapse and expansion. (User confirmed)
- Settings "General" group has "Shortcuts" page, centrally listing all keybindings: global shortcuts (open quick translation, translate selected text, clipboard history; omitted when feature disabled) and page switching are recorded here, registration errors display on corresponding rows; Esc collapse, Ctrl + drag, Enter / Shift+Enter / Tab in translation box are listed read-only. Each shortcut has only this single modification entry; translation and clipboard pages use a "Go to shortcuts" link. No onboarding guide or `?` popup. (User confirmed)
- Translation opening animation : in-island translation page expands from collapsed bar with springs just like todos and music, and fades in when switching pages; however, panel no longer adds 6px drop, only fading in (`.island--translation .island__expanded`) to prevent the tallest page from rushing down. Shows instantly when system requests reduce motion. Shortcuts opening in-island translation page use same animations. Independent translation window disables system display animations (`DWMWA_TRANSITIONS_FORCEDISABLED`), appearing in-place.
- Automatic direction judged by dominant language : compares foreign character count with Latin word count (one Han character has roughly 1.5 times the information density of an English word), excluding backtick code, links, and emails; translates to English if foreign characters dominate, otherwise translates to foreign language. Applies only to the picker's first choice, "Auto: English ↔ Chinese". Implemented in `src-tauri/src/translation/direction.rs`.
- Output language: the language bar reads "Auto-detect → [picker]". The source language is always detected; the picker chooses the output from 53 languages (English and Urdu among them), searchable by English name, the language's own name or its code, with the automatic choice first. New installs start on English; settings saved earlier without an output language stay on the automatic choice. Stored as `targetLanguage` in `skerry-translation-settings` (`auto` or a code from `features/translation/languages.ts`, mirrored in `src-tauri/src/translation/language.rs`); settings saved with the old `direction` migrate (`zh-en` to `en`, `en-zh` to `zh-CN`). (User requested)



- Translation shortcut can be disabled individually (Settings -> Translation -> Shortcuts, on by default): releases global shortcut when disabled, while translation itself remains accessible from island.
- Added two key-free services: Google Translate (public web interface, unreachable on some networks) and MyMemory (free daily quota, automatic segmenting for long text). When selected, hides model and API key rows; description notes suitability for looking up words and short phrases; unreachable network, rate limiting, and exhausted quota display localized prompt suggesting switching services.
