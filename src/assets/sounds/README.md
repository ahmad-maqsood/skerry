# Built-in Sound Effects

`thumb-piano/` contains the built-in sound effects ("thumb piano") for the island. Synthesized programmatically for Skerry: mellow fundamental tone, rapidly decaying metallic overtone, subtle echo, 24 kHz mono WAV. Melodies and timbres are original, not sourced from external software or asset libraries, and are distributed with this project under the MIT license.

| File | Event |
|---|---|
| `complete.wav` | Pomodoro / todo timer completed |
| `idle.wav` | Timer paused or awaiting user |

User-imported sound packs are not stored here; they are copied to `sound-packs/` in the application data directory.
